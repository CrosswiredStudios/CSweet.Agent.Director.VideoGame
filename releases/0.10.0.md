# 0.10.0

Supply current staffing approvals, fulfilled roster membership and verified resource readiness to planning decisions. A planning document's authority disclaimer no longer serves as a substitute for separately recorded approvals. Drafting, decomposition and estimates remain independent of execution readiness.

Reassess agent-authored planning escalations when their substantive context or review contract changes. Existing pending escalations can be superseded through the normal decision workflow when delegated management can resolve them. Human answers, CEO holds, QA dispositions and unrelated financial/scope decisions are preserved. Unchanged contexts do not repeat model reviews, and explicit decision replacements have no fixed traversal depth.

Requires SDK 5.32.0, WorkManagement.Contracts 5.9.0 and the matching host decision-authorship projection. Install through published releases and Installed Agents.

Validation: package-consumer regression tests, self-test and release artifact verification are recorded in the platform rollout document.

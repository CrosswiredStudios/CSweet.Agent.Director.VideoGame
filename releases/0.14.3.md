# 0.14.3

Updates the Director to `CSweet.Agent.SDK` 5.42.0. The test project uses the matching `CSweet.Agent.Testing` package to exercise pitch review through the SDK coordination dispatcher. Operating-state checkpoints and cached reviews now use the shared fixture for keyed reads, revision checks and writes. The pilot checks that an audio licensing question reaches the owner for the exact draft, and that the Director declines a stale revision before invoking the model. Run `dotnet test -c Release --filter Category=AgentHarness` from the repository root.

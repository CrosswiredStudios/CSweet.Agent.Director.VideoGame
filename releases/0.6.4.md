# 0.6.4

Completes the Director side of the work-board plan: every collaboration the Director starts for a game has an owning card.

- New cards, made with the SDK's `TrackedCollaboration` helper and bound to the project, the game board and the exact session:
  - "Agree the production brief with the Producer"
  - "Get the Creative Director's creative review"
  - "Get build capacity requested by the Technical Director"
  - "Get the Technical Director's toolchain feasibility review"
- A handoff card completes when its collaboration completes. When a participant reports Blocked, the card **waits** and shows who owns the next step and why, because that is usually a normal wait on another person. When the collaboration fails or is cancelled, the card is **Blocked**. Retry on the game board is offered for both, from the collaboration's own state.
- Why: on 2026-11-10 the production brief sat Blocked awaiting a creative review and the build-capacity request failed four times; neither was on the board.

Adding a card is idempotent per collaboration, so passes that re-read the same collaboration do not add duplicates. No new permissions. Requires `CSweet.Agent.SDK` 5.15.0.

Not in this release: the proposal card still uses its own 0.6.1 code.

Validation: not yet run. Written without a .NET SDK available; run `dotnet test` and the published output's `--self-test` before publishing.

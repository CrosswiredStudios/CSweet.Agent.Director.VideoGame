# 0.6.9

Review GDD substance independently of its document structure, and recover failed
creative turns without replaying stale submissions.

- `ReviewGddSemanticallyAsync` assesses creative intent, player experience, gameplay,
  presentation, planned acceptance, constraints and open decisions against the exact
  approved pitch. Prose, tables, renamed/reordered sections, any heading levels and
  other readable structures are supported. GDDs bypass the old heading, length and
  placeholder-word heuristics; other document-review policies are unchanged.
- The model returns coverage judgments, selected evidence and scope concerns. Code
  checks supporting passages, derives findings/disposition and binds all identity
  and authority. Invalid reviewer output gets one correction and an owned blocker;
  unavailable/invalid reviews are not cached as completed judgments.
- Acceptance with recorded coverage findings uses the platform's
  `accepted-with-findings` disposition. The exact revision must actually be accepted
  in the platform response before accepted project state or Producer handoff is saved.
- GDD request/result/feedback/failure records and keys now come from optional
  `CSweet.Agent.SDK.VideoGame.Contracts` 1.1.0. Typed generation failure codes drive
  retry; English matching remains only for retained pre-contract failures.
- Finalization never continues a blocked revision or reviews an older submission.
  A subsequent authorized resume relays retained exact feedback to Naomi.
- Regressions cover the SHATTERCHORD failure, raw third-party JSON exchanges and
  equivalent document formats, genuine missing content, invalid evidence, scoped
  retries, immutable platform rejection and duplicate delivery.

Publish contracts 1.1.0 first, then release/update Director 0.6.9 and Creative
Director 4.1.4 through Installed Agents. For an already Failed finalization, retry
first records the retained blocker; retry the resulting Blocked collaboration to
request a fresh revision. No live work, approvals or installed payloads were changed.

Validation: all 422 Director tests and 27 cross-role workflow tests pass, with the
actual SDK finalization validator exercised. The 0.6.9 self-test and pack pass.
Sibling SDK/work-contract/memory references were disabled; consumers used the packed
optional contracts 1.1.0 artifact. Nuspec, bundled manifest and dependency pin were
inspected, and the consumed contract DLL matches the final contracts package byte
for byte. Packages are local verification artifacts, not published releases.

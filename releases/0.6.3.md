# 0.6.3

Fixes found in the first live run of 0.6.2 (Qwen Games, 2026-11-10).

- **The proposal started before the board existed.** The board opened at 21:18:01 UTC; the Producer's proposal had started seven seconds earlier as a plain chat collaboration, so it had no owning card and no Stop or Retry on the board. The first board request after the team approval was refused and nothing recorded why. Opening the board is now retried up to four times, three seconds apart, inside the same pass, before the proposal is considered. If it still cannot open, the Director reports a `game-board-unavailable` progress entry with the capability, code and message, and the existing chat fallback applies.
- **The pitch and staffing-plan cards did not join the board.** They were selected by the game's intake fingerprint, which a game started from chat does not have. They are now selected by the card ids the Director already records (`VisionTodoId`, `StaffingTodoId`), plus the Producer documentation card for the accepted pitch.

Confirmed working in that run: the board is named after the game, and the design-document card was created, shown as bound to the board, project and session, and completed.

No new permissions. Requires `CSweet.Agent.SDK` 5.15.0.

Validation: not yet run. Written without a .NET SDK available; run `dotnet test` and the published output's `--self-test` before publishing.

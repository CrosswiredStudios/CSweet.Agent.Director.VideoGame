# 0.1.3

Restore sequential game onboarding. The Director first confirms collaboration, then asks what
kind of game the CEO wants, including deployment targets, technical choices, budget and other
constraints. It creates an Official Game Pitch for review; approval of that exact revision
continues to gate the Creative Director and Producer hiring proposal in every involvement mode.

Reporting setup now starts after the first pitch approval. Previously it immediately superseded
the initial collaboration question, leaving the Director idle after reporting preferences were
answered. Existing affected installations restore the missing discovery question once during
attention review or after completing reporting setup, while retaining saved preferences.

Validated with 254 passing tests, including actual decision-answer envelopes, question
supersession, upgrade recovery, and the full discovery-to-approved-pitch-to-hiring sequence.
Install using the Installed Agents update flow; no rehire or database repair is required.

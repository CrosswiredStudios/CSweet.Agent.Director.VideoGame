# 0.6.6

- **Request ownership corrects itself.** Classifying who owns an owner request now uses `AgentModelJson.ReadAsync`
  (SDK 5.21.1). A reply with an unknown owner, an empty or overlong reason, or no JSON goes back to the model with the
  exact problem, up to two corrections, before the request fails. The failure message now includes the problem.
- **Production brief review corrects itself.** The Director's review of the Producer's brief uses
  `AgentModelJson` with `PitchProtocol.NormalizeDirectorReview`: a missing suggested replacement becomes empty, and
  empty or overlong guidance, a missing or overlong owner question, or an overlong replacement is sent back with the
  exact problem instead of failing the turn.
- **Creative review failures can say why.** The Director still retries an incomplete creative review on the fixed
  text "Creative review did not return actionable, consistent findings." and now also when that text is followed by
  " Reason: <problem>". The reason is included in the retry request to the Creative Director and in the blocked
  status shown after three attempts. Creative Director 4.1.2 sends only the fixed text; a later Creative Director can
  add the reason once this Director is installed.
- The artifact semantic review is unchanged: it goes through the calendar-aware chat call and already turns an
  unreadable reply into a blocking finding.
- SDK 5.15.0 to 5.21.1 and WorkManagement contracts 5.3.0 to 5.4.0 for package builds (local builds already use the
  sibling checkouts).

Why: QFN Games' production brief stalled on 2026-11-11 after three rejected creative reviews, and the owner saw only a
generic "incomplete" status.
